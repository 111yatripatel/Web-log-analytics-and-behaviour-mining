                        📐 Distributed System Architectural Blueprint
                    

                    
Five-tier decoupled architecture separating batch compute from low-latency serving

                


                

                    

                        
TIER 1

                        
Ingestion & Preprocessing

                        
Python 3 Streaming Tokenizer

                        
Streams raw multi-hundred megabyte access logs line-by-line in O(1) memory. Normalizes timestamps, sanitizes invalid requests, and outputs clean TSVs with 99.99997% accuracy.

                        
Runtime: 16.03s (3.46M rows)

                    


                    

                        
TIER 2

                        
Distributed Storage

                        
Apache Hadoop HDFS 2.7.4

                        
Stores normalized TSV across 3 physical 128 MB blocks with replication factor 2.0. Secondary DataNode replica provides immediate high availability in case of container failure.

                        
Health: 100% (0 missing replicas)

                    


                    

                        
TIER 3

                        
Distributed Compute

                        
YARN & MapReduce & Hive 2.3.2

                        
YARN schedules mappers and reducers across 2 NodeManagers. Hive executes SQL aggregations, while custom Streaming jobs mine user sessions and URL transition graphs.

                        
Parallel Speedup: 1.69x – 1.94x

                    


                    

                        
TIER 4

                        
Serving Store

                        
MongoDB 6.0 Document Engine

                        
Aggregated analytical collections with compound B-Tree indexes decouple heavy batch computing from user dashboard interactions, eliminating live queries on Hadoop.

                        
Index Lookup: Sub-millisecond

                    


                    

                        
TIER 5

                        
Application Gateway

                        
FastAPI & Modern Web UI

                        
Non-blocking asynchronous REST API serves analytics to the browser. Delivers interactive visual charts, session search, and pipeline simulation in < 2 ms latency.

                        
Latency: < 2 ms response time

                        🚀 NASA Historic Dataset & Big Data Methodology Deep-Dive
                    

                    
Detailed provenance, historical context, and mathematical algorithms implemented in this project

                


                

                    

                        
Dataset Provenance

                        
Captured by the web server at NASA Kennedy Space Center in Florida over a 2-month period in 1995:

                        
    
                            
  • July 1995: 1,891,715 requests (205 MB raw)
    • 
                            
  • August 1995: 1,569,898 requests (168 MB raw)
    • 
                            
  • Historical Peak: July 13, 1995 launch of Space Shuttle Discovery (STS-70).
    • 
                        

                    


                    

                        
30-Min Sessionization Formula

                        
User session demarcated by inactivity time gap between consecutive requests from identical host:

                        

                            $$\Delta t = t_{k+1} - t_k > 1800 \text{ seconds}$$
                        

                        
Implemented via Hadoop secondary sort on (host, epoch) with O(1) memory per reducer.

                    


                    

                        
2-Stage Graph Mining Architecture

                        
Partitioning key changes between stage 1 and stage 2:

                        
    
                            
  • Stage 1 (Intra-Session): Grouped by host to extract directed transitions $(u \to v)$.
    • 
                            
  • Stage 2 (Global Frequencies): Grouped by composite key (source_url, dest_url) to calculate global edge weights.
    •
