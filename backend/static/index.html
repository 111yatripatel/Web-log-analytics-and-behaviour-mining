🎓 Big Data Systems Viva Defense Cheatsheet
Architectural justifications and oral exam answers
1. Why use HDFS with replication instead of storing files on local disk?
HDFS splits large datasets into 128 MB blocks distributed across multiple DataNodes. Replication factor 2 guarantees that if DataNode 2 experiences hardware failure, DataNode 1 immediately serves the requested blocks without downtime or data loss. Local disks lack horizontal scaling and single-point-of-failure recovery.
2. What happens inside Mapper, Shuffle/Sort, and Reducer in our Sessionization job?
• Mapper (session_mapper.py): Parses raw logs and emits (host, epoch, timestamp, url, bytes).
• Shuffle & Sort: Hadoop automatically hashes the key (host), routes identical hosts to the same reducer, and groups their requests.
• Reducer (session_reducer.py): Chronologically sorts each host's hits, detects gaps > 30 minutes to demarcate new sessions, and outputs session summaries.
3. Why is URL Navigation Mining split into two MapReduce stages?
• Stage 1 must group records by host to extract consecutive page transitions within active sessions.
• Stage 2 must group records by transition pair (source_url -> dest_url) to sum global frequencies across all users.
Because the partitioning key changes from host to (source, dest), a 2-stage MapReduce pipeline is the classic Big Data paradigm.
4. Why is MongoDB used as the serving layer rather than querying Hive directly from FastAPI?
Hadoop and Hive are optimized for high-throughput batch processing over terabytes (query response time ~15–40 seconds). Web dashboards require interactive response times (<10 milliseconds). Pre-aggregating results into MongoDB document collections with B-Tree indexes decouples analytical computation from low-latency serving.
5. Why is this not a simple Pandas analytics script?
Pandas loads datasets entirely into a single machine's RAM and fails when data exceeds available memory. Our pipeline distributes storage across HDFS DataNodes, executes jobs via YARN across multiple worker containers, streams data line-by-line in constant O(1) memory, and uses MapReduce shuffle partitioning.
