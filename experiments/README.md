# Scalability & Benchmarking Experiment

## Objective
To empirically evaluate the scaling behavior and execution performance of Hadoop MapReduce running on YARN as input workload scales horizontally.

## Methodology
1. **Base Workload (1x)**:
   - Real normalized NASA HTTP server access log dataset (`3,461,612` records, `329.40 MB`).
   - Stored in HDFS with replication factor = 2 across DataNode 1 and DataNode 2.
2. **Synthetic Scale-Up Workloads (2x, etc.)**:
   - Generated by repeating records from the real dataset.
   - Distinctly labeled as synthetic workloads derived from real data.
3. **Execution Metrics**:
   - Number of Map tasks launched (determined by HDFS input splits).
   - Number of Reduce tasks (configured to 2 for cluster demonstration).
   - Measured wall-clock time from YARN job submission to completion (`_SUCCESS`).
   - CPU and memory consumption reported by YARN Job Counters.

## Running the Benchmark
```powershell
python experiments/generate_benchmark.py
```
Results are saved to `data/benchmarks/benchmark_results.json` and documented in `docs/BENCHMARKS.md`.
